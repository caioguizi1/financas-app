# Fluxo

App pessoal de finanças (PWA) — controle de gastos e projeção do saldo futuro.

- Abra no Safari do iPhone e use **Compartilhar → Adicionar à Tela de Início**.
- Os dados ficam salvos só no aparelho (localStorage). Faça backup em **Ajustes → Exportar backup**.
- Hospedado via GitHub Pages a partir da branch `main`.

## Versões
- **v1.1** — salário em duas partes (adiantamento + restante / quinzena) no cadastro inicial.
- **v1.0** — cadastro inicial uma pergunta por tela, projeção de 90 dias com gráfico, lançamento rápido, cartões com fechamento/vencimento e parcelas, fixos, extrato mensal, ajuste de saldo, backup.
